## 🧩 Brain Teaser

**Puzzle:** You have three switches outside a closed room. One controls a light bulb inside. You can operate the switches as often as you like, but enter the room only once. How do you determine which switch controls the bulb?

<details>
<summary>💡 Reveal the solution</summary>

1. Turn on switch one and wait several minutes.
2. Turn switch one off, then turn switch two on.
3. Enter the room.

- If the bulb is lit, switch two controls it.
- If the bulb is off but warm, switch one controls it.
- If the bulb is off and cool, switch three controls it.

*This assumes a bulb that becomes warm when illuminated.*

</details>

## 🧠 Quick Tech Quiz

**Which protocol protects web traffic using TLS?**

- A. FTP
- B. HTTP
- C. HTTPS
- D. Telnet

<details>
<summary>✅ Reveal the answer</summary>

**Correct answer: C — HTTPS.**

HTTPS uses TLS to protect data exchanged between a client and a web server.
